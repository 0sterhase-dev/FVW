# Ferienhaus Valentin — Oberammergau

Modernes, responsives One-Page-Webprojekt für ein Ferienhaus in Oberammergau bei München.

## Funktionen
- Automatische Sprachwahl über die Browser-Sprache
- Automatische Darstellung über `prefers-color-scheme`
- Burger-Menü mit Animation auf Mobilgeräten
- Airbnb-Button
- Google-Maps-Link
- E-Mail- und Telefon-Buttons
- Mobilefreundliches Layout
